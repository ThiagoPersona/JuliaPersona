# JuliaPersona — material de estudo

Material de estudo da Julia para os processos seletivos da UEM (Universidade Estadual de Maringá).

## Pastas

- **[PAS1/](PAS1/)** — PAS/UEM, Etapa 1 (1º ano do Ensino Médio), 2026. Abra `PAS1/index.html` no navegador para estudar. Comece por `PAS1/README.md`.

O PAS/UEM tem 3 etapas, uma por ano do Ensino Médio (Etapa 1 no 1º ano, Etapa 2 no 2º ano, Etapa 3 no 3º ano). Quando a Julia avançar de série, o material da próxima etapa deve entrar em uma pasta nova (`PAS2/`, depois `PAS3/`), seguindo a mesma estrutura de `PAS1/` — cada etapa tem programa de prova e provas anteriores próprios.
